# NFTS

A TypeScript monorepo managed by [Turborepo](https://turbo.build/repo).

## Project Structure

- `apps/`: Example Applications
- `packages/`: Packages and libraries

## Getting Started

This project uses [Yarn](https://yarnpkg.com/) as its package manager.

### Prerequisites

- Node.js (v25+)
- Yarn (v4+) - Enable via `corepack enable`

### Installation

```bash
yarn install
```

### Development

Run all apps in development mode:

```bash
yarn dev
```

### Build

Build all apps and packages:

```bash
yarn build
```

### Linting

Run linting across the workspace:

```bash
yarn lint
```
